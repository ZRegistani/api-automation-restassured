# API Automation Framework - Rest Assured

Enterprise-style REST API automation framework built using Java, Rest Assured, TestNG, and Maven for scalable backend API validation and automated testing.

---

## Tech Stack

- Java
- Rest Assured
- TestNG
- Maven
- JSON Schema Validation
- Git & GitHub

---

## Framework Features

- REST API automation testing
- Reusable API test structure
- TestNG integration
- JSON response validation
- Maven dependency management
- Scalable framework architecture
- Git version control integration

---

## Project Structure

```text
src/test/java
│
├── base

├── tests

```
